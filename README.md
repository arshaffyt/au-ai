# UC — AI Shopping & Services

A responsive, luxury dark-theme **front-end MVP** for UC (Universe Commerce), a concept platform combining product discovery and service discovery.

## Features in this starter
- Responsive landing page for desktop and mobile
- Product catalogue with category filters and search
- Add-to-bag interaction and subtotal calculation
- Wishlist interactions
- Service category showcase
- Premium dark visual system with gold accents
- No build tools or package installation required

## Run locally
1. Download and unzip this project.
2. Open `index.html` in a modern browser.

For a local development server, you can use VS Code with the Live Server extension.

## Publish with GitHub Pages
1. Create a GitHub account (if you do not already have one).
2. Create a new repository named `uc-ai-shopping-services`.
3. Set it to **Public** if you want it to be openly accessible.
4. Upload the files and folders in this project (not the ZIP file itself).
5. Open the repository's **Settings → Pages**.
6. Under Build and deployment, choose **Deploy from a branch**.
7. Select the `main` branch and `/ (root)`, then Save.
8. Wait for GitHub Pages to publish your site. The Pages screen will show its URL.

## Important limitations
This is a starter front-end demo, not a production marketplace. Product listings and prices are sample data. Checkout, payments, customer accounts, real service-provider booking, admin tools, inventory, databases, and AI features are **not connected**. Do not accept real payments or collect sensitive customer data with this demo.
